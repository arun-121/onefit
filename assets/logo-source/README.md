# OneFit app icon

The mark is the Material Symbols "sprint" glyph (Rounded, filled, weight 600), white on the
Material 3 baseline primary `#6750A4`, with no container shape. Material Symbols are by Google,
under the Apache License 2.0.

- `android-icon-*.svg`: adaptive icon layers (108-unit canvas, glyph 40 units, inside the safe zone)
- `icon.svg`: the full icon for legacy launchers
- `splash-icon*.svg`: the glyph alone for the light (`#EADDFF`) and dark (`#1D1B20`) splash screens

The PNGs in `assets/images/` are rendered from these at 1024 px.
